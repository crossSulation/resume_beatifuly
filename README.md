# 简历编辑助手

基于 Vite + React + TailwindCSS + TypeScript 的简历编辑器：编辑完整简历，预览排版效果，并用 LLM 逐条优化经历描述、提供可落地的改进建议。

## 快速开始

```bash
npm install
npm run dev
```

## 接入真实 LLM

两种方式任选其一：

### 1. 设置弹窗（推荐，无需重启）

点击页面右上角 ⚙️，填写 API Key、接口地址（OpenAI 兼容）、模型名称与温度，点「保存」立即生效；还可用「测试连接」验证配置。设置保存在浏览器 localStorage。

### 2. 环境变量（提供默认值）

复制 `.env.example` 为 `.env.local`，填入配置后重启开发服务器：

```env
VITE_LLM_API_KEY=sk-your-key
VITE_LLM_BASE_URL=https://api.openai.com/v1
VITE_LLM_MODEL=gpt-4o-mini
```

服务层使用 OpenAI 兼容的 Chat Completions 接口（`src/services/llm.ts`），支持任意兼容网关。设置弹窗中的配置优先于环境变量；未配置 API Key 时自动使用内置模拟数据，方便先跑通界面。

## 功能

- 完整简历编辑：基本信息、个人简介、工作经历、项目经历、教育经历、专业技能
- 经历区块支持添加 / 删除 / 排序，职责条目可自由增删
- 逐条「✨ 优化」：LLM 改写该条目，返回改进建议与建议补充的量化指标，一键应用
- 「一键美化」：批量改写个人简介与全部经历条目，逐条勾选确认后统一应用，未勾选的保留原文
- 「JD 定制」：粘贴目标岗位职位描述，按 JD 关键词改写条目，并给出关键词命中 / 缺失分析
- 「体检报告」：本地规则即时扫描（量化比例、强动词、弱表达、超长条目、占位符）+ 可选的 LLM 深度分析（招聘官视角评估、风险与评分）
- 「补全数据」：把 [X%]、[N 人] 等占位符逐条替换为真实数据，实时预览效果
- 撤销 / 重做（含 Ctrl+Z / Ctrl+Shift+Z 快捷键），支持 50 步历史
- JSON 备份导入 / 导出，防止浏览器缓存丢失
- 编辑 / 预览双模式，预览为可直接阅读的简历排版
- 导出 PDF（A4 多页）、导出带样式的独立 HTML、复制 Markdown
- 预览模式下可直接 Ctrl/Cmd + P 打印为 PDF（矢量文字，效果更佳）
- 本地自动保存（localStorage），刷新不丢失
